# 动态样本数据集（point-in-time / 当期全样本）

这是练习一的**正确口径**样本：每个时点只用"当时真正在交易"的股票（退市的踢掉、新上市的纳入），
避免幸存者偏差，也避免"把今天的股票倒填回过去"的前视偏差。

## 价格数据在哪里？

价格数据**就是全样本** `../data/daily/`（5321 只，后复权），**无需再复制一份**。
原因：每只股票的文件天然只覆盖它实际上市 ~ 退市的交易日区间——

- 退市股（如乐视网 300104）的数据**止于退市日**，之后没有行；
- 新股（如宁德时代 300750）的数据**始于上市日**，之前没有行。

所以"每年排除退市、加入新上市"已经天然编码在价格数据里，直接用它就是动态口径。

## 本文件夹内容

| 文件 | 说明 |
|---|---|
| `universe.csv` | 5558 只，含每只的 `list_date`（上市日）和 `delist_date`（退市日，现存股为空） |
| `membership_by_year_end.csv` | 每年末（2015-12-31 ~ 2024-12-31）当时的活跃股票清单（year_end, code, name），共 40486 行 |

## 怎么用（任意回测日期 t 的活跃股票）

```python
active = uni[(uni["list_date"] <= t)
             & (uni["delist_date"].isna() | (uni["delist_date"] > t))]
```

- 每年末活跃股票数：2015 年 2807 只 → 2024 年 5119 只（逐年递增，见 `membership_by_year_end.csv`）。

## 两个实验口径对比

| 口径 | 数据集 | 说明 |
|---|---|---|
| **动态（正确）** | `data/daily` + 本文件夹的 universe | 每个时点用当时真实的股票池 |
| **静态（有偏）** | 用"今天还在的股票"做回测 | 幸存者偏差 + 前视偏差 |

拿这两个口径跑同一个 20 日反转因子，收益差就是幸存者偏差造成的"高估"。
