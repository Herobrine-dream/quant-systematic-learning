# 练习一 · 数据体检：亲手造一次幸存者偏差 —— 完整报告

> 练习目标：取 2015–2024 全部 A 股日线（含退市股），用"仅现存股"和"含退市的当期全样本"两个股票池跑同一个反转因子，量化幸存者偏差。

---

## 一、思路

**核心问题**：回测时用错股票池（universe），策略的表现会被系统性扭曲。其中最常见、也最隐蔽的一种，就是**幸存者偏差（survivorship bias）**——只用"今天还活着的股票"回测，等于自动丢弃了那些已经退市的股票。

而退市的股票，绝大多数是**一路跌到退市的输家**。一个反转因子（买跌）恰恰会去买入它们。如果回测里这些股票不存在，策略就"躲过了"本应承受的亏损，收益会被**高估**。

所以本练习的思路是：
1. 先**显式地**把退市股的历史数据补回来（对抗平台的默认"现存股列表"）；
2. 用"仅现存股 vs 含退市全样本"两个口径，跑同一个反转因子；
3. 用差值量化"幸存者偏差让我高估了多少"。

**关键认知**：`股票池 = 策略的第一道生死线`。因子和模型再精妙，若池子本身选错，结论就是错的。

---

## 二、具体过程

### 2.1 数据获取

| 项 | 内容 |
|---|---|
| 数据源 | 东方财富历史行情（akshare）；退市清单来自上交所、深交所 |
| 股票宇宙 | 沪深 A 股 **5558 只**（现存 5221 + 已退市 337），不含北交所与 B 股 |
| 日线数据 | **5321 只**有数据、**9,244,796 行**，2015-01-05 ~ 2024-12-31 |
| 复权口径 | **后复权（hfq）** |
| 字段 | date / code / open / close / high / low / volume / amount |

**"坑"的落实**：平台默认列表只给现存股，因此单独拉取了上交所、深交所的退市清单，把 337 只退市股补进宇宙——这是本次练习数据层面最关键的一步。

### 2.2 数据清洗（遇到并解决的三个坑）

1. **复权口径**：实测发现东方财富的**后复权对退市整理期/缩股股**、**前复权对高分红现存股**都会产生负价，且两种复权的收益率并不一致（差约 2%）**不能混用**。最终选定：统一后复权 + 剔除"任何 OHLC ≤ 0"的异常行。
2. **剔非正价**：共剔除 **1865 行 / 27 只**（占总量约 0.02%），其中 600870 ST厦华（破产重整缩股致 4 年 hfq 异常）占 70%、600091 占 26%，其余均 <5%。
3. **网络失败**：首轮 320 只因代理限流失败，已全部重爬补回，最终**零失败**。

### 2.3 两种股票池（口径）

- **动态口径（正确，point-in-time）**：交易日 t 满足 `上市日 ≤ t < 退市日`。退市股只在其退市前可用、新股只在其上市后可用。
- **静态口径（有偏，幸存者）**：只有"今天还上市"的股票可用，退市股永远剔除——这正是大多数平台默认给的列表。

两者唯一差异 = 那 **254 只有数据的退市股**，是幸存者偏差的干净来源。

### 2.4 因子与回测

- 因子：**N 日反转**（过去 N 日收益率取负号），N ∈ {5, 10, 20, 60}
- 调仓：每 21 个交易日一次，买入信号最高（跌最多）的前 20%，同时记录信号最低（涨最多）的前 20% 作对照
- 组合：等权；年化按月频折算；无风险利率取 0；未计交易成本

### 2.5 IC 计算（练习核心指标）

每个调仓期计算一次横截面 **RankIC**（信号与下一期收益的 Spearman 秩相关），再汇总成 IC均值 / IC标准差 / ICIR / IC>0占比。

## 三、结果

### 3.1 幸存者偏差的"底数"（每年末股票数）

| 年份末 | 当时存在 | 现在还在 | 差值（已退市） |
|---|---|---|---|
| 2015-12-31 | 2807 | 2576 | **231** |
| 2016-12-31 | 3033 | 2801 | 232 |
| 2017-12-31 | 3466 | 3232 | 234 |
| 2018-12-31 | 3566 | 3335 | 231 |
| 2019-12-31 | 3759 | 3537 | 222 |
| 2020-12-31 | 4138 | 3930 | 208 |
| 2021-12-31 | 4601 | 4412 | 189 |
| 2022-12-31 | 4903 | 4755 | 148 |
| 2023-12-31 | 5094 | 4990 | 104 |
| 2024-12-31 | 5119 | 5067 | 52 |

> 差值逐年递减，是因为越晚的年份留给"退市"的时间越短。2015 年那档，有 231 只（占当时 8.2%）后来退市了——若只用现存股，这 231 只就被悄悄丢掉了。

### 3.2 因子有效性（IC）

| 因子 | IC均值 | ICIR | IC>0占比 |
|---|---|---|---|
| 5日反转 | 0.036 | 0.246 | 56% |
| 10日反转 | 0.050 | 0.327 | 63% |
| **20日反转** | **0.085** | **0.520** | **69%** |
| 60日反转 | 0.070 | 0.412 | 64% |

- 全部 IC 为正、正值占比 >50%：**反转效应在 A 股真实存在**。
- **20 日反转最强**（月度反转），5 日最弱（短期噪音），60 日仍偏反转。

### 3.3 回测收益（年化，多空价差）

| 因子 | 动态口径 | 静态口径 | 夏普（动态） |
|---|---|---|---|
| 5日反转 | 5.53% | 5.72% | 0.33 |
| 10日反转 | 14.07% | 14.20% | 0.78 |
| **20日反转** | **26.76%** | **27.45%** | **1.39** |
| 60日反转 | 19.33% | 20.24% | 0.97 |

做多（买跌）为正、做空（买涨）为负 → 反转利润来自"抄底"，追涨会被惩罚。

### 3.4 幸存者偏差（练习的答案）

**对回测收益：高估约 1%/年**

| 因子 | 做多(买跌)高估 | 多空价差高估 |
|---|---|---|
| 5日反转 | +0.94% | +0.19% |
| 10日反转 | +0.90% | +0.14% |
| 20日反转 | +1.23% | +0.69% |
| 60日反转 | +1.35% | +0.91% |

**对 IC：几乎无影响**（静态−动态 IC均值差仅 0.0001 ~ 0.0016）。

**验收结论**：

> "幸存者偏差让我的反转策略**年化收益高估了约 1%（0.9%~1.35%）**，但对 IC 的影响微乎其微（<0.002）。"

**为何收益动、IC 不动**：收益是绝对值（丢掉 254 只亏损样本 = 直接抬升收益）；IC 是横截面排序相关（抽掉约 5% 的样本点，排序几乎不变）。

## 四、练习意义

1. **股票池是策略的第一道生死线**：同样的因子、同样的回测代码，只因为股票池从"动态全样本"换成"仅现存股"，年化收益就虚增约 1%——这在低换手、年化几个点的策略里已是很大的误差。
2. **必须显式拉取历史全样本**：平台默认列表就是"现存股"，这是最大的坑；退市股的历史数据要单独补。
3. **IC 好 ≠ 回测可信**：本练习最反直觉的一点——幸存者偏差对 IC 几乎没有影响，但落到收益上就露出马脚。**只看 IC 会低估幸存者偏差的严重性**，最终要落到"收益/净值"层面交叉验证。
4. **数据质量决定结论质量**：负价、复权口径混用、网络失败、空股等数据问题，任何一个没处理好，都可能悄悄污染结论；"将错就错"是量化里最贵的行为。

---

## 五、局限与可改进处

- 未计交易成本、无风险利率取 0、等权、前 20% 分位、月频——均为简化设定。
- 持有期内退市股用 skipna 剔除，退市当月亏损未完全计入，实际幸存者偏差可能更大。
- 样本含多轮牛熊，反转因子时变性明显（可看 `反转因子_IC时间序列.csv`）。
- 更严谨可做：按上市日期动态纳入的"市值加权/分层"版本，或对 600870 等缩股股用"不复权+手工缩股复权"。
