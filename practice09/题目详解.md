# 练习 09 · 归因（Attribution）详解

> 配套教材《量化系统化学习与实战教程》第五章 · 难度 ★★★
> 本文把"归因"从概念、数学、每一步思路到陷阱完整讲一遍，作为做题前的总地图。

---

## 0. 一句话与为什么重要

**归因 = 把"我赚了多少钱"拆成"我靠什么赚了这些钱"。**

```
总超额收益 3.89%（一个光秃秃的数字）
        │  归因拆解
        ▼
 行业配置贡献 + 个股选择贡献 + 风格暴露贡献 + 纯 Alpha（各有名字、各有大小）
```

表面看练习 08 的组合有年化超额 3.89%，但"3.89%"本身什么都说明不了。归因要回答：这块超额里，**有多少是押对行业、有多少是选对股、有多少只是吃到了小盘/价值/低波动的风格溢价、真正属于自己的选股本事还剩多少**。

**为什么重要**：一个数字不会告诉你能力在哪里、会不会持续。拆开之后你才知道——

- 业绩是**稳定可复制**的，还是**靠一两个行业/一种风格撞运气**的；
- 你标榜的"选股 Alpha"，是不是其实只是"打包了风格 beta"。

> 这是量化从"会算收益"走向"会理解收益"的一步，也是业绩归因（performance attribution）这门职业的核心。

---

## 1. 两种归因总览（先定位题目在干嘛）

练习 09 把两种归因都做了，它们从两个不同角度拆同一个超额：

| 维度 | 拆法 | 用的"语言" | 回答的问题 |
|---|---|---|---|
| **业务归因**（Step 1 Brinson） | 行业配置 vs 个股选择 | 行业（业务语言） | "我押对行业了吗？行业内选对股了吗？" |
| **因子归因**（Step 2 风格回归） | 风格暴露 vs 纯 Alpha | 因子（学术语言） | "我赚的是风格的钱，还是真本事？" |

两者互补：

- **Brinson** 用"行业"这个看得见摸得着的维度拆，适合和基金经理/客户沟通（"你今年超额主要来自超配了新能源"）。
- **风格回归** 用"因子"这个学术维度拆，直接接上你前面练习发现的结论（练习 03 小盘溢价、练习 08 小盘 tilt），把"暴露"量化成"钱"。

## 2. 第一步：Brinson 归因（行业配置 vs 个股选择）

### 2.1 它在干嘛

把一个组合相对基准的超额收益，拆成**三项**。设 `w` = 权重、`r` = 收益、`p` = 组合、`b` = 基准、`i` = 第 i 个行业：

```
配置贡献（Allocation）  = Σ (w_p,i − w_b,i) × (r_b,i − R_b)      ← 行业超配/低配 × 该行业相对全市场的超额
选择贡献（Selection）   = Σ w_b,i × (r_p,i − r_b,i)             ← 基准行业权重 × 你选的股相对该行业的超额
交互贡献（Interaction） = Σ (w_p,i − w_b,i) × (r_p,i − r_b,i)   ← 两者交叉（既超配又选对）
```

三项加起来 = 组合收益 − 基准收益 = **总超额**（R_p − R_b）。

> **口径说明**：这里"配置贡献"用的是 **Brinson–Fachler** 变体（用 `r_b,i − R_b`，即行业相对"整个基准"的超额）。还有另一种老变体 Brinson–Hood–Beebower（用 `r_b,i` 本身）。两种只是把"基准整体收益"这块的归属划分得不同，总量一致；做题时**固定用一种、全文一致**即可，最常用 Fachler。

### 2.2 每一项的字面意思

- **配置贡献（Allocation）**：你**超配**了某个行业（w_p > w_b），而那个行业恰好**跑赢全市场**（r_b,i > R_b），这一项为正。赚的是**"自上而下、押对行业"**的钱。
- **选择贡献（Selection）**：不管行业配多配少，**在你配置的每个行业内**，你选的这批股票**跑赢了该行业指数本身**（r_p,i > r_b,i），这一项为正。赚的是**"自下而上、行业里选股"**的钱。
- **交互贡献（Interaction）**：既超配了行业、又在该行业内选对了股，两件事的交叉。量通常很小，很多归因表直接并入"选择"里，只报两列（配置 / 选择）。

### 2.3 一个迷你例子（把公式变成直觉）

假设市场只有两个行业，基准 = 行业 A 50% + 行业 B 50%：

| | 行业 A | 行业 B |
|---|---|---|
| 基准权重 w_b | 50% | 50% |
| 组合权重 w_p | 70%（超配） | 30%（低配） |
| 行业基准收益 r_b,i | +10% | 0% |
| 组合在该行业收益 r_p,i | +8%（选股跑输行业） | +4%（选股跑赢行业） |

- 基准收益 R_b = 0.5×10% + 0.5×0% = **5%**
- 组合收益 R_p = 0.7×8% + 0.3×4% = **6.8%**
- 总超额 = 6.8% − 5% = **1.8%**

拆开：

- 配置贡献 = (0.7−0.5)×(10%−5%) + (0.3−0.5)×(0%−5%) = +1% + 1% = **+2%**（超配了跑赢的 A，低配了跑输的 B，押对行业）
- 选择贡献 = 0.5×(8%−10%) + 0.5×(4%−0%) = −1% + 2% = **+1%**（A 内选股跑输、B 内跑赢，净赚）
- 交互贡献 = (0.7−0.5)×(8%−10%) + (0.3−0.5)×(4%−0%) = −0.4% − 0.8% = **−1.2%**（既超配 A 又选输 A，双重吃亏）

三项合计 = +2% + 1% − 1.2% = **+1.8%** ✅ 对上了。

**这个故事说明**：这个人超配了 A、A 也涨了（配置赚 +2%），但他在 A 里选股选得差（交互 −1.2%），全靠 B 行业内的选股（+1%）救回来——归因把"他到底强在哪、弱在哪"看得清清楚楚。

### 2.4 它的意义

归因把你的能力**画像**出来：

- 配置贡献是大头 → 你是**配置/择时型**选手，换一批股票结果也差不多，业绩取决于"行业判断准不准"。
- 选择贡献是大头 → 你是**选股型**选手，行业判断错了也不致命。
- 归因表还能看出**哪几个行业贡献最大**、贡献是稳定分布还是靠某一两个行业爆发——如果全靠"某年超配了暴涨的 X 行业"，这份业绩就不扎实、不可复制。

> 落到练习 08：你的组合是"中证 500 成分内前 100 等权"，本身就带行业偏离（等权 ≠ 市值加权）。这一步就是把那个偏离**量化成钱**，看它是正贡献还是负贡献。

## 3. 第二步：风格归因（5 个风格代理 + 时序回归）

### 3.1 它在干嘛

跑一条**时间序列回归**，把组合的超额收益回归到 5 个风格因子的收益上：

```
r_p,t − r_f,t = α + β1·市值 + β2·估值 + β3·动量 + β4·波动 + β5·换手 + ε_t
```

### 3.2 关键前提：每个"风格因子"本身是一列多空组合收益

这里最容易误解——风格因子**不是**"某只股票的大小"，而是**一列随时间变化的"多空组合收益"**（每个调仓期一个值）：

| 风格因子 | 标准构造（A 股口径） | 学术对应 |
|---|---|---|
| **市值** | 做多小市值、做空大市值 | SMB |
| **估值** | 做多高 BP/EP（便宜）、做空低 BP/EP（贵） | HML |
| **动量** | 做多过去涨得好的、做空跌得多的 | WML |
| **波动** | 做多低波动、做空高波动 | VOL（低波异象） |
| **换手** | 做多低换手、做空高换手（换手负向） | 流动性/换手 |

这 5 列因子收益就是回归的自变量 X，你的组合超额收益是 Y，**每个月（或每天）一行**。

### 3.3 回归结果里三个东西

- **α（截距）**：把 5 个风格能解释的部分都扣除后，**剩下来的、风格解释不了的超额收益**。这才是通常说的**"真 Alpha"**——纯粹来自你的选股，而不是你恰好重仓了小盘/价值/低波动。判断它是否真有意义，看 **t 值**（t < 2 就是不显著，别当能力）。
- **β_k（各风格系数）**：你的组合在每个风格上的**暴露程度**。β_市值 = 0.4 意味着你的组合相当于"自带 40% 的小盘因子仓位"。
- **R²**：这 5 个风格**一共解释了你收益波动的多少**（0 到 1 之间）。

### 3.4 它的意义

它把 Step 1 里"业务语言"的归因，翻译成**"学术/因子语言"**，并**直接接上你前面练习已经发现的事**：

- 练习 03 你发现 ln市值 IC = −0.0498（强小盘溢价）；
- 练习 08 你发现指增组合市值暴露差 = −0.318（比基准偏小盘 27%）。

风格归因就是把这两条线索**变成钱**：那个 −0.318 的市值暴露，到底贡献了多少超额？如果市值因子 β 很大、且市值因子本身长期正收益，那你的超额里很大一块其实是**"小盘 beta"**，不是你的本事——这是 Step 2 最核心的洞察。

## 4. 第三步：如果 R² > 0.8，说明什么？

这是一道**判断题**，答案是一句警告：

> **R² 高 = 你的收益绝大部分是风格 beta，不是 Alpha。**

具体拆开说：

1. **R² = 0.8 意味着收益波动的 80% 都能被 5 个风格因子解释。** 也就是说，你的策略本质上是"**用一组风格因子打包出来的组合**"，用几个风格 ETF 就能近似复制你，不需要什么独特选股能力。

2. **对应的 α 会很小、而且很可能不显著。** 真正属于自己的超额（截距）占比很小。看 α 的 t 值——t < 2 说明"你其实没有产生显著 Alpha，只是吃到了风格溢价"。

3. **这不是"错"，但必须诚实标注。** 分两种情况：
   - 如果目的就是赚风格溢价（叫 **smart beta / 风格配置**），高 R² 没问题，只是要明白：**风格溢价会拥挤、会回撤**（小盘溢价 2017 年就崩过一次），业绩持续性依赖风格是否延续。
   - 如果你标榜自己是"选股 Alpha 策略"，那 R²>0.8 就是**打脸**——说明你没有独立选股价值，把风格暴露误当成能力了。

4. **反过来，R² 低（比如 0.2~0.4）也不等于就是 Alpha。** 因为没被风格解释的可能是"真 Alpha"，也可能是**别的没放进回归的因子**（行业、质量），或者干脆是**运气/噪声**。所以判断 Alpha 要靠"截距是否显著（t 值）"，R² 只告诉你"风格解释了多大部分"。

> **一句话结论**：R²>0.8 说明"赚的是风格的钱、不是选股的钱"，Alpha 含量低，策略更像 beta 打包。

## 5. 与练习 08 的衔接（可复用什么 + 预期结论）

### 5.1 直接复用练习 08 的产出

| 练习 09 需要 | 复用练习 08 的 | 说明 |
|---|---|---|
| 归因对象 | 中证 500 指增组合 | 月度调仓、成分内前 100 等权 |
| 组合持仓/权重 | 每期组合权重 | 用于算 r_p,i（组合各行业收益） |
| 基准收益 | `data/benchmark_close.csv` | 中证 500 日线 |
| 行业分类 | 练习 03 的申万一级 `industry_map.csv` | 分行业归因 |
| 风格因子构造 | 练习 05 的因子（反转/动量/换手/EP 等） | 转成多空组合收益 |

### 5.2 两条已知线索（做题时对照验证）

1. **市值暴露差 −0.318（偏小盘）** → 风格归因里**市值因子 β 大概率显著为正**，而小盘因子在 A 股长期是正收益 → 你的超额里很大一块是"小盘 beta"，**不是 Alpha**。这正是 Step 3 判断题的实战答案。
2. **行业偏离（前 100 等权 vs 市值加权基准）** → Brinson 里**配置贡献可能为负**（等权天然超配小行业、低配大行业），要靠选股贡献去填。

> 所以练习 09 其实是在**给练习 08 那个漂亮的 3.89% 超额"查户口"**：拆完你可能会发现，3.89% 里真正属于自己的、风格解释不了的部分，可能只有 1% 出头，甚至不显著——**这不是坏事，而是把"看起来的强"变成"诚实理解自己赚的是什么钱"**，这才是这一级练习想教的东西。

## 6. 关键陷阱（按严重程度排序）

1. **前视偏差**：用现在的行业分类/现在的成分，去归因过去的收益。→ 用每个调仓时点当时的行业分类和成分（PIT 纪律）。
2. **把 beta 当 alpha**：不拆风格，直接把风格暴露贡献的收益算成"我的选股能力"。→ 必须做 Step 2 的回归，看 β 和 α。
3. **只看 R²，不看 α 的 t 值**：R² 高/低都不直接等于"有/没有 Alpha"，Alpha 要靠截距显著性判断。
4. **复权口径混用**：风格因子里估值/市值类必须用**不复权价**（见项目 §五.1，练习 03 已踩过），收益类才用 hfq。
5. **Brinson 变体混用**：Fachler 和 Hood–Beebower 两种"配置贡献"公式不同，全文只能固定用一种。

## 7. 求职视角 / 常见面试问题

业绩归因是量化/FOF/基金评价岗位的日常，面试常问：

1. "你的超额收益是怎么来的？" —— 用 Brinson 表答（行业配置 vs 个股选择）。
2. "怎么证明你的超额是 alpha 不是 beta？" —— 用风格回归的 α + t 值 + R² 答。
3. "R² 很高说明什么？" —— §4，高 R² = 风格 beta 打包，Alpha 含量低。
4. "Brinson 归因和因子归因有什么区别？" —— §1 的表（业务语言 vs 学术语言）。
5. "小盘 tilt 怎么在归因里体现？" —— 风格回归里市值因子 β 显著为正。

**一句话定位这个项目在简历上怎么写**：
> "对中证 500 指增组合做 Brinson 归因与风格归因：行业配置/个股选择贡献拆分 + 5 因子时序回归，
> 识别出超额收益主要来自小盘市值暴露（β≈X.XX），扣除风格后纯 Alpha 为 X.X%（t = X.XX，显著/不显著），
> 风格解释度 R² = X.XX。"
