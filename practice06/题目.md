# 练习 06 题目：真实回测改造（成本、涨跌停、停牌、T+1）

> 来源：教材《量化系统化学习与实战教程》第五章 · 难度 ★★★

**目标**：让你的回测从"好看"变成"可信"。

**步骤**
1. 拿练习 05 最好的组合，做以下改造并逐一记录影响：
   - 涨停不买、跌停不卖；
   - 停牌不可交易（调仓日跳过）；
   - 次日开盘价成交（而不是当日收盘价）；
   - 加入成交量约束（单笔不超过当日成交额 5%）；
   - 成本从 0 → 0.05% → 0.1% → 0.2% → 0.3%。
2. 画出"收益-成本"曲线，算出**盈亏平衡成本**。

**验收**：一张改造前后对比表（每一步让年化掉了多少）+ 盈亏平衡成本数字。**这个数字就是你策略的安全边际。**
