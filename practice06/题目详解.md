# 练习 06 题目详解：真实回测改造（成本、涨跌停、停牌、T+1）

> 来源：教材《量化系统化学习与实战教程》第五章 · 难度 ★★★

## 一、题目回顾

**目标**：让练习 05 那个"好看"的回测变成"可信"的回测。

**步骤**
1. 拿练习 05 最好的组合（IC 加权），逐项改造并记录影响：
   - 涨停不买、跌停不卖；
   - 停牌不可交易（调仓日跳过）；
   - 次日开盘价成交（而非当日收盘价）；
   - 成交量约束（单笔 ≤ 当日成交额 5%）；
   - 成本 0 → 0.05% → 0.1% → 0.2% → 0.3%。
2. 画收益-成本曲线，算**盈亏平衡成本**。

**验收**：改造前后对比表（每一步让年化掉了多少）+ 盈亏平衡成本（= 策略安全边际）。

---

## 二、回测框架：从"每期独立"升级为"持仓滚动"

练习 05 的回测是"每期独立买入 top20% 持有 20 日"，期与期之间没有持仓连续性。但练习 06 的"**跌停不卖 / 停牌顺延**"必须跨期跟踪持仓——今天卖不掉的股票要带到下一期，所以必须改成**持仓滚动模拟**：

> 每期 t：算目标持仓 → 确定「要买」和「要卖」名单 → 在成交日按约束执行 → 得到本期实际持仓 → 记录持仓从本期成交价到下一期成交价的收益。

- `holdings`：上期留下的实际持仓（集合）。
- `target`：本期按 IC 加权得分选出的 top20%（目标持仓）。
- `buy = target - holdings`（新买入），`sell = holdings - target`（要卖出）。
- 加约束后得到 `buy_exec` / `sell_exec`，实际持仓 = `(holdings - sell_exec) ∪ buy_exec`。
- 单边换手 = 实际卖出股数 ÷ 持仓数（首期 = 买入比例），成本 = 单边成本 × 单边换手。

## 三、五项改造的实现方法

### V0 基线：当日收盘价成交（复现练习05）
- 成交价 = `close[t]`（调仓日收盘），持有到 `close[t+H]`，收益 = `close[t+H]/close[t]-1`。
- 无任何约束，成本 0.1%。**结果应与练习 05 的 IC 加权一致**（用于校验框架没改坏）。

### V1 次日开盘价成交（T+1 决策滞后）
- 成交价 = `open[t+1]`（次日开盘），持有到 `open[t+H+1]`（下一期成交日开盘）。
- 收益 = `open[t+H+1]/open[t+1]-1`，持有期仍为 H 日，只是整体平移约一天。
- 这一步吃掉的是**信号滞后一天的衰减**——反转是快信号，一天之差损失明显。

### V2 涨停不买、跌停不卖
- 涨跌停价 = `round(前收盘价 × (1±幅度), 2)`，幅度见下节。
- **涨停不买**：`buy` 里，成交日开盘价 ≥ 涨停价 → 买不进，剔除。
- **跌停不卖**：`sell` 里，成交日开盘价 ≤ 跌停价 → 卖不出，继续持有到下期。

### V3 停牌不可交易
- 停牌股在日线数据里**缺行**（本项目 `volume==0` 的行为 0），pivot 后 `open` 为 NaN。
- 成交日 `open` 为 NaN → 买不进、卖不出（跳过）。

### V4 成交量约束（单笔 ≤ 当日成交额 5%）
- 假设组合规模 **1 亿**（用户确认），每期目标 k 只，单笔目标买入金额 = `1亿/k`。
- 约束：`buy` 里，成交日 `amount × 5% < 1亿/k` → 当日容量不够，买不进，剔除。
- 不补位（买不进就少买），这是教材练习的简化。

### 成本扫描与盈亏平衡
- 在 V4 全约束版本上，单边成本取 `0 / 0.05% / 0.1% / 0.2% / 0.3%`，画年化 vs 成本曲线。
- **盈亏平衡成本** = 组合年化 == 全A等权基准年化 时的成本。扫描范围内无交点则用最后两点**线性外推**。

## 四、关键口径（换对话后勿推翻）

1. **涨跌停判断必须用不复权价**：涨跌停是交易所按**不复权价**四舍五入到分算的，用后复权价会因复权因子判错（呼应记忆 `hfq-valuation-factor-caveat`）。收益仍用后复权价算。
2. **涨跌停幅度从代码+名称推断**：`688`/`300`/`301` → 20%；名称含 `ST` → 5%；其余 → 10%。无北交所代码（universe 只有 SZ/SH）。
3. **停牌 = 成交日无行情（open 为 NaN）**，而非 `volume==0`（本项目停牌股直接缺行）。
4. **成交量约束的组合规模 = 1 亿**（自由参数，用户拍板）。
5. **换手与成本口径沿用练习05**：单边换手 × 单边成本，保证 V0 能对齐练习05。
