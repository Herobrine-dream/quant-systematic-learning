# 量化调仓方式详解

> 定位：跨练习的方法论参考文档。练习 05 起开始做"因子 → 组合"，调仓方式就是决定"信号怎么变成持仓、再变成收益"的那一环。
> 本文系统梳理量化投资里主流的调仓方式，按四个独立维度展开，每个方式给做法、公式/伪代码、优缺点、适用场景，并标注与本项目练习的对应关系。

---

## 一、为什么调仓方式重要

调仓（rebalance / reweight）是**"信号 → 收益"的最后一公里**。同样的因子信号，用不同的调仓方式执行，最终收益可以差出好几个百分点。原因有三：

1. **换手成本**：每买卖一次都要付佣金、印花税、滑点。调仓太频繁，alpha 被成本吃掉。
2. **冲击成本**：大单砸进去会推高买入价、压低卖出价，成交价和你回测里用的价不是一回事。
3. **执行偏离**：理想持仓（信号想要的）和实际持仓（你真正拿到的）之间总有差距，调仓方式决定这个差距多大。

一句话：**因子决定"买什么"，调仓方式决定"什么时候买、买多少、花多少成本"。**

---

## 二、总览：调仓的四个独立维度

调仓方式不是一个单一选择，而是四个正交维度的组合：

| 维度 | 回答的问题 | 常见选项 |
|---|---|---|
| ① 触发时点 | **什么时候**调？ | 定期 / 阈值走廊 / 事件驱动 / 混合 |
| ② 换仓幅度 | **调多少**？ | 全仓重建 / 差额换仓 / 只加不减 / 缓冲带 |
| ③ 目标权重 | **调成什么**权重？ | 等权 / 市值加权 / 因子加权 / 优化器 |
| ④ 成本约束 | 调仓时**受什么限制**？ | 换手预算 / 成本感知 / 冲击约束 |

> 例：练习 06 的组合是「**定期(20日)** × **差额换仓** × **IC因子加权** × **固定单边成本**」的组合。任何一个维度都可以单独升级。

## 三、维度①：触发时点（什么时候调）

### 3.1 定期调仓（calendar rebalancing）

- **做法**：按固定日历周期全量重算——每日 / 每周 / 每月 / 每季度。到点就执行，不管有没有必要。
- **本项目**：练习 01~06 全部是 20 日定期调仓（约每月一次）。
- **优点**：简单、可复现、无参数、易于回测。
- **缺点**：到点就调，即使持仓根本没偏离目标也会产生无谓换手；反之，两次调仓之间若权重已大幅漂移却只能干等。
- **适用**：因子信号本身以固定频率更新（财报季、月度因子）的场景。

### 3.2 阈值 / 走廊调仓（threshold / tolerance-band rebalancing）

- **做法**：为目标权重设一个**容忍带**，实际权重漂移出带子才调回。

```
设目标权重 w_target = 20%，容忍带 ±3%（即允许 17% ~ 23%）
每期检查：
    若 |w_actual - w_target| ≤ 3%   → 不动
    若 |w_actual - w_target| > 3%   → 调回目标（或调回带边界，更省换手）
```

- **优点**：只在"确实偏离太多"时才交易，能显著压换手；是**组合管理（尤其指数增强、多资产）最标准的做法**。
- **缺点**：多一个"带多宽"的参数要选；带太窄等于定期调仓，带太宽则持仓长期偏离目标。
- **适用**：权重自然漂移（涨跌引起）比信号变动更频繁的场景。

### 3.3 事件驱动调仓（event-driven rebalancing）

- **做法**：出现特定事件才动手，平时不动。
- **典型事件**：财报公告（PIT 因子更新）、指数成分股调整、ST / 退市、涨停打开、并购重组、因子值跳变。
- **本项目**：练习 06 的"停牌顺延、跌停不卖"本质上就是事件驱动——发生"卖不出"的事件就顺延到下一期。
- **优点**：精准，只在信息真正更新时交易。
- **缺点**：事件要能可靠识别和回测，否则容易漏掉或前视。

### 3.4 混合调仓（calendar + threshold）

- **做法**：**定期检查，但只有偏离超过阈值才执行**。
- **优点**：既有定期调仓的纪律（不会永远不调），又保留阈值调仓的省换手。
- **适用**：**业界最常用**——几乎所有带成本的实盘组合都用这个。

## 四、维度②：换仓幅度（调多少）

> 这是之前讨论的核心。先厘清一个常见误解。

### 4.1 全仓重建（full rebalance）

- **做法**：每期把旧持仓**全部清掉**，再全部买成新的目标持仓。
- **优点**：逻辑最简单，回测好写。
- **缺点**：换手成本最大；很多股票其实上期也在目标里，却被"卖了又买"白白烧成本。
- **本项目**：练习 05 的收益计算等价于"每期全仓重建"，但成本只按"新旧重叠率"近似扣（见 4.2 的记账技巧）。

### 4.2 差额换仓（incremental rebalance）

- **做法**：只卖出"跌出目标"的，只买入"新进目标"的，其余继续持有。`sell = 旧持仓 − 目标`，`buy = 目标 − 旧持仓`。
- **本项目**：练习 06 的持仓滚动就是这个。
- **优点**：换手只发生在真正变化的股票上。
- **缺点**：需要跨期跟踪持仓状态（比"每期独立"复杂）。
- **关键**：无约束时，4.1 和 4.2 的**持仓和收益完全等价**，差别只在换手成本的记账精度。

### 4.3 只加不减 / 只减不加（buy-and-hold / sell-only）

- **做法**：只做单向——要么只买入新信号、永不卖（纯做多累积），要么只卖出、停止加仓（建仓/清仓阶段）。
- **适用**：建仓期、减仓期、或"买入并长期持有"策略（价值投资、低换手动量）。
- **注意**：**只加不减不是"调仓"**，它是放弃调仓，靠买入时的选股质量赚长期收益。

### 4.4 缓冲带（buffer）——因子选股压换手的利器

- **做法**：买入阈值和卖出阈值**分开**，中间留一个"死区"。

```
买入线 = 因子排名前 10%     （未持仓的股票，排名进前 10% 才买）
卖出线 = 因子排名后 30%     （已持仓的股票，排名跌到后 30% 才卖）
中间 10%~30% 的持仓        → 不动
```

- **原理**：一只票在排名阈值附近反复横跳（今天第 18%、明天第 22%）会触发"卖了又买"，白白烧换手。缓冲带让"已经拿着的"更不容易被踢出去，只有真正变差才卖。
- **优点**：几乎不损失 alpha，却能显著降换手（通常降 20%~50%）。
- **缺点**：持仓会略微偏离严格的 top20%；多两个参数（买入线、卖出线）。
- **本项目**：练习 05/06 的 top20% 是"买入线=卖出线=20%"的零缓冲版本，升级成缓冲带即可压换手。

## 五、维度③：目标权重（调成什么权重）

> 如果"动态调仓"指的是"权重随时间变化"，那这一层才是本质。

### 5.1 等权（equal weight）

- **做法**：每只票权重 = 1/N，恒定。
- **优点**：零参数、无信息、分散最好、回测最干净。
- **缺点**：无视股票之间的质量差异，也无视市值差异（会系统性偏小盘）。
- **本项目**：练习 01~06 组合内部都是等权持有。

### 5.2 市值加权（cap weight）

- **做法**：权重 ∝ 市值。大盘股占更多。
- **特点**：这是"市场组合"，是被动基准（如沪深300、中证500 就接近市值加权），不是主动 alpha 来源。
- **用途**：通常作为**基准**，而不是策略本身。

### 5.3 因子加权（factor score weighting）

- **做法**：权重 ∝ 因子得分（或其变体）。
- **本项目**：练习 05 的三种合成就属于这层——
  - **等权合成**：多因子得分求平均；
  - **IC 加权**：`wᵢ ∝ 历史ICᵢ均值`（按预测强度）；
  - **ICIR 加权**：`wᵢ ∝ 历史ICᵢ均值 ÷ 历史ICᵢ标准差`（按强度÷稳定性）。
- **优点**：直接承接信号，简单可解释。
- **缺点**：不直接控制风险、不控制换手。

### 5.4 优化器生成权重（optimization-based）

> 进阶主流，练习 07~09 大概率会碰到。核心是"把目标写成约束下的最优化问题"。

**（a）均值-方差优化（Markowitz）**
- `max  wᵀμ − (λ/2)·wᵀΣw`，约束 `Σw = 1`、`w ≥ 0`。
- 权衡收益 μ 和风险 Σ。理论优美，但**对 μ 和 Σ 的估计误差极敏感**（"垃圾进垃圾出"），实务中 μ 通常用因子 alpha 替代、Σ 用收缩估计。

**（b）风险平价（risk parity）**
- 让每个资产/因子的**风险贡献相等**（每单位资金承担相同风险）。
- 等价于 `max Σ ln(wᵢ)`（等风险预算），朴素近似就是 `wᵢ ∝ 1/波动率ᵢ`。
- 特点：不需要预测收益，只靠波动率/协方差，稳健；是桥水"全天候"的思想内核。

**（c）Black-Litterman**
- 把**市场隐含均衡收益**（reverse optimization 反推）与**你的主观观点**（views）+ **观点置信度**融合，得到后验收益，再做均值方差。
- 特点：解决了"纯优化器对输入太敏感"的痛点，观点可加可减、可设置信度。

**（d）最大化因子暴露（factor-maximization / 组合优化选股）**
- `max  wᵀ·score`，约束：行业中性、市值中性、个股权重上限/下限、**换手上限**等。
- 这是**A股多因子选股的主流**：不再是"买 top20% 等权"，而是用优化器求"在约束下因子暴露最大的那组权重"。
- 特点：把行业/市值中性化、个股权重、换手预算全部变成硬约束，是最"生产化"的做法。

## 六、维度④：成本与换手约束

### 6.1 换手预算（turnover budget）

- **做法**：每次调仓限制最大换手，如 `Σ|w_new − w_old| ≤ 20%`，超过就只执行一部分。
- **优点**：直接给成本设上限，防止信号频繁变动时过度交易。
- **实现**：常作为优化器的硬约束，或事后按比例缩减交易量。

### 6.2 成本感知调仓（transaction-cost-aware）

- **做法**：只在"**换仓带来的预期收益 > 交易成本**"时才动手，否则维持现状。
- **优点**：把"调仓"本身变成一个收益-成本决策，而非机械动作。
- **本项目**：练习 06 的盈亏平衡成本就是它的思想雏形——成本高过安全边际，调仓就不划算。

### 6.3 冲击约束与分批执行（impact / phased execution）

- **做法**：大单不一次砸完，用 TWAP（时间加权）/ VWAP（成交量加权）分笔成交，或设"单笔 ≤ 当日成交额 N%"的硬约束。
- **本项目**：练习 06 的"成交量约束（单笔 ≤ 当日成交额 5%）"就是冲击约束的简化版。

## 八、从简单到进阶的升级路径

给本项目（练习 05 之后的路线）的建议升级顺序，按"性价比"排序：

1. **差额换仓 + 持仓滚动**（✅ 练习06 已完成）—— 让约束能跨期生效。
2. **缓冲带**（推荐下一步）—— 几乎零成本地压换手，直接改善练习05/06 的 0.49 换手。
3. **混合调仓（定期检查 + 阈值执行）**—— 把"到点必调"改成"偏离才调"。
4. **换手预算 + 成本感知**—— 练习09 防过拟合时，把成本当硬约束。
5. **最大化因子暴露（优化器）**—— 练习07/08 指增/归因的最终形态。

## 九、速查：本项目目前用的是什么

- **触发时点**：定期（20 交易日，约每月）
- **换仓幅度**：差额换仓 + 持仓滚动（练习06）
- **目标权重**：组合内部等权；因子层面 IC/ICIR 加权（练习05）
