# 练习 07 题目详解：防过拟合三件套

> 配套教材《量化系统化学习与实战教程》第五章 · 难度 ★★★
> 本文把题目里出现的每个概念，从"是什么、为什么、怎么算"三层讲透，作为做题前的地图。

---

## 0. 先记住一句话（贯穿全文）

> **历史数据 = 真规律（signal） + 随机运气（noise）。过拟合 = 你误把"运气"当成了"规律"。**

练习 01~06 做的所有事，本质都是：**用 2015–2024 的历史数据，调出一个"看起来能赚钱"的策略**。
致命陷阱是：你可能只是"对着答案调参数"，在历史里很好看，一到未来就崩。这个陷阱叫**过拟合（overfitting）**。

练习 07 用三个工具检查自己的策略是不是过拟合：

1. **参数网格热力图** —— 看"尖峰"还是"平原"；
2. **Walk-forward（前推/滚动样本外检验）** —— 用"过去选、未来验"的诚实方式看样本外还剩多少；
3. **试验次数诚实记录 + p 值校正** —— 数清楚自己给"运气"发了多少张抽奖券，并把假阳性管住。

---

## 1. 热力图（heatmap）

**它是什么**：一张"表格填颜色"的图，本质是画一个函数

```
f(参数A, 参数B) = 某个结果（年化收益）
```

本题的横纵轴是：

- 横轴：调仓周期（5/10/20/40/60 日）
- 纵轴：回看窗口（10/20/40/60/120 日）
- 每格填：这一组参数的年化收益，高 = 红、低 = 蓝

25 组参数画成 5×5 的颜色图，一眼看出"哪片区域好、哪片差"，跟气温地图一个道理。

**横纵轴可以换**：A 和 B 是任意两个可调参数/选项都行，例如

- 去极值倍数 × 中性化方法
- 买入分位（前 10% / 20%）× 单边成本
- 回看窗口 × 持有天数

参数越多、可调格子越多，过拟合风险越大——所以这题只挑两个给你练。

---

## 2. 尖峰 vs 平原（spike vs plateau）

看完热力图，问：**好结果是一大片，还是孤零零一个点？**

**尖峰（坏，过拟合信号）：**

```
        回看窗口
      10  20  40  60  120
调仓5   ▓   ▓   ▓   ▓   ▓    ▓ = 蓝 = 亏
   10   ▓   ▓   ▓   ▓   ▓
   20   ▓   ▓   █   ▓   ▓    ← 只有这一格红，四周全蓝
   40   ▓   ▓   ▓   ▓   ▓
   60   ▓   ▓   ▓   ▓   ▓
```

只有"调仓20 + 回看20"这一格特别赚，旁边"调仓20 + 回看40"立刻变亏。
说明这个"好"很可能是**碰巧**——参数稍一动就崩，真实世界里你不可能精确踩中那一格。

**平原（好，稳健）：**

```
        回看窗口
      10  20  40  60  120
调仓5   █   █   ▓   ▓   ▓    █ = 红/橙 = 赚
   10   █   █   █   ▓   ▓
   20   █   █   █   █   ▓    ← 一大片相邻格子都红/橙
   40   ▓   █   █   █   ▓
   60   ▓   ▓   █   █   ▓
```

一大片相邻参数都还行，说明这个逻辑**本身**有效，不靠精确踩参数，拿到未来更可能继续有效。

> 用练习 01 的真实结果对照：20 日反转最强，但 10 日也还不错 → 这是"平原"的迹象；
> 如果 10 日和 40 日都稀烂、只有 20 日好，那就是"尖峰"。

## 3. 热力图的"致命问题"：为什么全样本选参必然高估

### 发生了什么

热力图是**站在 2024 年底，把 2015–2024 全部数据看完后**，才选出收益最高的那一格。问题就出在"全看完了"。

### 为什么会高估 —— 拆成"真规律 + 运气"

假设反转策略的**真实本事**（稳定、未来也存在的部分）是年化 **+4%**。但你在历史上测出的每一格，都不是刚好 +4%，而是：

```
测出来的收益 = 真本事 + 这一格的运气
              =  +4%   +  随机波动（可正可负）
```

25 个格子 = 25 次"抽运气"。有的测出 +6%，有的测出 +1%。
**你选的是最好的那一格**——25 次抽签里，最好那次的运气天然是正的、而且是正得最多的，就像买 25 张彩票挑那张中奖的。

示意（数字是比方，道理是真的）：

```
真实本事 = +4%（稳定）
最好那格测出来 ≈ +9%      ← 热力图看到的是这个
但这格的真实未来期望 ≈ +4% ← 运气不会重复，明年重摇一次
```

- 热力图告诉你 +9%（= 4% 本事 + 5% 运气）
- 未来只能拿到 ~+4%（运气重摇，平均归零）
- 差的那 +5%，就是"对着历史调参数"吹出来的泡沫

### 一句话总结

> 全样本挑参数 = "事后诸葛亮"。你让运气也参与了评选，选出来的冠军必然带着运气加成；
> 运气不可复制，所以样本外必然缩水。

## 4. Walk-forward（前推 / 滚动样本外检验）

**它是什么**：强制模拟"真实做量化的人只能往前看、不能偷看未来"的过日子过程。

真实做量化的人，在 2018 年 1 月 1 日，**只知道 2015–2017，不知道 2018 会怎样**。他能做的只有：

1. 拿 2015–2017 调参数、挑出最优；
2. 2018 年真实去跑；
3. 到了 2019 年 1 月，手头多了一年数据（2016–2018），再重新挑一次，跑 2019；
4. 如此往复。

Walk-forward 就是用程序把"过日子"演一遍：

```
时间轴：2015 ─ 2016 ─ 2017 ─ 2018 ─ 2019 ─ 2020 ─ 2021 ─ ...
        └───训练───┘  └─测试─┘
            └───训练───┘  └─测试─┘
                └───训练───┘  └─测试─┘
                    └───训练───┘  └─测试─┘
```

- 每轮：用**前面 3 年**（训练）挑参数，用**后面 1 年**（测试）验结果；
- 测试那一年，在挑参数时是**"封起来"没碰过的**——它是诚实的未来；
- 4 个测试年拼起来 = **样本外表现**。

### 和热力图的对比（核心）

| | 热力图（全样本） | Walk-forward |
|---|---|---|
| 挑参数时用了几年的数据 | 2015–2024 全部 | 只用测试年**之前**的 3 年 |
| 测试数据是不是"没见过" | 不是（全看过） | 是（真的没见过） |
| 结果代表什么 | 历史最优，含运气 | 未来可期待的真实水平 |

所以 walk-forward 的数字几乎一定比热力图低，低掉的部分就是你之前"偷看未来"占的便宜。

## 5. "训练"和"测试"具体指什么

两个词从机器学习借来，量化里含义简单：

- **训练（train）＝ 用一段数据去"调参数 / 定策略"**。
  本题中：在训练段里跑 5×5 网格，选出收益最高的（调仓周期, 回看窗口）组合。这段数据是"给你学习的"。
- **测试（test）＝ 拿另一段你没用来调参的数据，检验这个策略到底行不行**。
  这段数据在训练时被"封存"了，你不看它。

**为什么要分两段？** 如果同一段数据既调参又检验，等于"自己出题自己判卷"，当然满分。
必须用**没参与过评选**的数据打分，分数才真实。

类比：**训练 = 做模拟题；测试 = 高考**。把模拟题背熟是满分，但那是背题不是会，真实水平要看没见过的题考几分。

经济学含义：训练 = 用**过去的信息**形成投资信念/策略；测试 = 把信念放到**未来的真实决策**里看赚不赚钱。
你只能用过去信息做决策，所以"训练在前、测试在后"正好对应真实投资的时间逻辑。

## 6. 为什么第 4 步要"诚实记录试了多少个因子"

因为**每试一次，就给"运气"发了一张抽奖券**。

- 试 1 个因子：运气蒙对的机会 1 次；
- 试 100 个因子：运气蒙对的机会 100 次。

哪怕 100 个因子**全无真本事**，也很可能撞出几个"历史上很好看"的——就像掷 100 次硬币总会出现一段"连出 10 次正面"的假象。

诚实记录数量，是为了知道**自己有多大概率是被运气骗的**。而且它和第 7 节直接挂钩：试得越多，判断"显著"的标准就得越严（Bonferroni/BH 在干的事）。

> 附加一层：这也是自我审计。人倾向"只记得赚钱那次、忘掉试废的 99 次"，写下来强制诚实。

## 7. p 值、Bonferroni、BH —— 含义与算法

### 7.1 p 值是什么

**直觉**：p 值回答一个反事实问题——

> "假设我这个因子**其实一点用都没有**（纯噪声），那我还能测出现在这么强（甚至更强）的结果，概率有多大？"

- p 很小（如 0.01）→ 纯噪声下很难撞出这么强 → 结果大概率不是运气，是真本事；
- p 很大（如 0.5）→ 纯噪声下很常见 → 结果可能就是运气。

**数学定义**：

```
p = P( 观测到的统计量 ≥ 实际值  |  零假设 H0 为真 )
```

零假设 H0 = "因子无效（真实 IC = 0 / 策略超额 = 0）"。

**怎么算出来**（拿 IC 举例）：反转因子在每个调仓日有一个 IC 值，共 n 期（如 120 期）：

```
IC 均值  = m
IC 标准差 = s
t 统计量 = m / (s / √n)      ← 注意分母除以 √n
```

回忆：ICIR = m / s，所以 **t = ICIR × √n**（这两个量你在练习里都见过）。

p 值 = 2 × P(T > |t|)，T 服从 t 分布（大样本近似标准正态），查表/程序算即可。

**用真实数字**：练习 01 反转因子 IC 均值 0.085、ICIR 0.52、约 120 期
→ t ≈ 0.52 × √120 ≈ 0.52 × 10.95 ≈ **5.7** → p ≈ 1e-8，几乎为 0。
含义：若反转纯属噪声，撞出 t=5.7 的概率百亿分之一，所以它几乎肯定有真本事。

**经济学含义**：p 值 ≈ "你把运气当本事的受骗概率"。p < 0.05 = 允许 5% 受骗率。

### 7.2 但 p 值有个大坑（多重检验）

上面的 5% 是"**只试 1 次**"的受骗率。本题试 **25 组参数**，问题变成：

> 25 次独立检验，每次允许 5% 假阳性，那么"**至少出现 1 次假阳性**"的概率是多少？

```
1 − (1 − 0.05)^25 = 1 − 0.95^25 ≈ 1 − 0.28 ≈ 72%
```

**72%！** 哪怕 25 组参数全是垃圾，也有 72% 概率撞出至少一组"p<0.05、看起来很显著"。
此时你单独看那一组 p=0.03 就信了，其实是被 25 次抽奖骗了。

这个"至少一次假阳性"的概率，专业叫**族系错误率（FWER）**。校正的目的就是把 72% 重新压回 5%。

### 7.3 Bonferroni 校正

**目标**：把"25 次里任何一次假阳性"的总概率控制在 5% 以内。

**做法（简单粗暴）**：阈值 0.05 除以试验次数 m：

```
新阈值 = α / m = 0.05 / 25 = 0.002
```

每个 p 值必须 < 0.002 才算显著（等价于把 p × m 后再和 0.05 比）。

**数学原理（并集上界）**：

```
P(至少一次假阳性) ≤ P(第1次假) + P(第2次假) + … + P(第m次假)
                   ≤ m × (α/m) = α
```

**用数字**：假如 25 组里最好的那组 IC 的 p = 0.01。
单独看 0.01 < 0.05，显著；Bonferroni 后 0.01 > 0.002，**不显著**——很可能是 25 次抽奖撞出来的。

**经济学含义**：极度保守，宁杀错不放过；代价是"漏掉真因子"（第二类错误上升）。
适合因子少、要铁证如山的场景。

### 7.4 BH（Benjamini–Hochberg）校正

**目标**：不控制"任何一次假阳性"，而是控制**假阳性占比**——宣布显著的这堆结果里，最多允许 5% 是假的。这叫 **FDR（错误发现率）**，比 Bonferroni 宽松。

**做法（排序法）**：

1. 把 m 个 p 值从小到大排：p₁ ≤ p₂ ≤ … ≤ p_m；
2. 找最大的 k，满足：

```
p_k  ≤  (k / m) × q      （q 通常取 0.05）
```

3. 宣布 p₁ ~ p_k 这 k 个"显著"，其余不显著。

**手算例子**（5 个 p 值，q = 0.05）：

| 排序 k | p 值 | 门槛 (k/5)×0.05 | 满足? |
|---|---|---|---|
| 1 | 0.001 | 0.01 | ✓ |
| 2 | 0.010 | 0.02 | ✓ |
| 3 | 0.030 | 0.03 | ✓ |
| 4 | 0.200 | 0.04 | ✗ |
| 5 | 0.400 | 0.05 | ✗ |

最大的满足 k = 3 → 前 3 个显著。（Bonferroni 门槛 0.05/5 = 0.01 则只让前 2 个通过——BH 更宽松。）

**经济学含义**：量化选因子的实际场景常用 BH。你确实要试很多因子、允许一部分是"运气混进来的"，只要**混进来的比例别太高**即可，不必像 Bonferroni 把好因子也毙掉。

### 7.5 三者关系一句话

| 工具 | 控制什么 | 严格程度 |
|---|---|---|
| 单独 p 值 | 单个检验的假阳性率 | 最松（被 25 次检验骗） |
| Bonferroni | 族系里"**任何一次**假阳性"的概率 | 最严 |
| BH | 族系里"假阳性**占显著结果的比例**" | 中间 |

## 8. 把全部串回练习 07

- **第 1 步（热力图）**＝ 25 个格子，全样本看哪个最好 → 但这是**含运气的**。
- **判断尖峰/平原**＝ 看"好结果"是孤立一点还是一大片（孤立点 = 运气嫌疑大）。
- **第 3 步（walk-forward）**＝ 换"用过去选、拿未来验"的诚实方式，看样本外还剩多少。
- **第 4 步（记录试验数）**＝ 数清楚自己给运气发了多少张抽奖券。
- **加分项（Bonferroni/BH）**＝ 把 25 次检验的假阳性重新管住，不让 p<0.05 骗你。
