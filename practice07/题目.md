# 练习 07 题目：防过拟合三件套

> 来源：教材《量化系统化学习与实战教程》第五章 · 难度 ★★★

**目标**：亲手体验"参数稍一动就崩"。

**步骤**
1. 对调仓周期（5/10/20/40/60 日）和回看窗口（10/20/40/60/120 日）做网格，画年化收益热力图。
2. 判断：是"尖峰"还是"平原"？
3. 做 Walk-forward：3 年训练 + 1 年测试，滚动 4 次，看样本外表现。
4. 记录你至今一共试了多少个因子变体（诚实）。

**验收**：热力图 + Walk-forward 表 + 试验次数记录 + 结论（"我的策略是平原还是尖峰"）。

**加分**：用 Bonferroni 或 BH 校正你的 p 值。
