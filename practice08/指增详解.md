# 练习 08 · 指数增强（Index Enhancement）详解

> 配套教材《量化系统化学习与实战教程》第五章 · 难度 ★★★
> 本文把"指增"从概念、数学、每一步思路、陷阱到求职视角完整讲一遍，作为做题前的总地图。

---

## 0. 一句话与为什么重要

**指数增强 = 贴着指数走，同时用因子多赚一点。**

```
组合收益 = 基准(中证500)收益 + 超额收益(alpha)
```

它是量化私募最主流的真实产品（中证 500 / 中证 1000 指增），招聘最看对口，所以题目说"求职最对口的项目"。

**和练习 01~07 的根本区别**：之前的策略是"全市场选股、不看基准"，赚**绝对收益**（大盘涨你也涨、跌你也跌）。指增赚的是**超额**——大盘涨你涨更多、跌你跌更少，客户只为"多出来的那一点"付钱。

---

## 1. 三种投资方式（先定位"指增"在哪）

| 方式 | 干什么 | 收益来源 | 例子 |
|---|---|---|---|
| **被动（指数基金）** | 完全复制指数，权重照抄 | 只有 beta（市场收益） | 中证500ETF |
| **主动（选股）** | 自己选股票，大幅偏离指数 | beta + alpha，但 beta 占比大 | 主动股基 |
| **增强（指增）** | 贴着指数，小幅偏离 | beta + 稳定的小 alpha | 中证500指增 |

指增是"被动和主动的中间态"：**大部分仓位跟着指数走（控制偏离），小部分主动倾斜（赚 alpha）**。

---

## 2. 核心概念（逐个讲透）

### 2.1 基准（benchmark）

拿来对比的"标尺"，本题是**中证 500 指数**（代码 `000905`）。

- 它是 500 只中盘股的加权篮子，权重主要按**自由流通市值**。
- 每天有指数涨跌幅 = 基准日收益 `r_b`。

### 2.2 超额收益（excess return / alpha）

```
超额日收益 e_t = 组合日收益 r_p,t − 基准日收益 r_b,t
```

- `e_t > 0`：这天你比指数多赚（或少亏）。
- 把所有 `e_t` 连起来，就是**超额净值曲线**（起点 1，逐日累乘 `1+e_t`）。
- **报告只看这条曲线和它的统计量，不看组合绝对收益**——这是验收里"标题写超额"的原因。

### 2.3 跟踪误差（Tracking Error，TE）

```
TE = std(超额收益序列)      （日度超额 × √252 年化）
```

- 度量你**偏离指数有多大**。TE 越大，说明你越不"像"指数，越接近主动选股。
- 直觉：TE=4% 意味着你的组合和指数平均每年差 4 个百分点的波动。
- **它既是风险也是自由度**：TE 太小 = 没发挥出因子；TE 太大 = 不叫增强，叫主动。

### 2.4 信息比率（Information Ratio，IR）★ 最重要

```
IR = 年化超额 / 年化跟踪误差
   = mean(e_t) / std(e_t) × √252     （日度超额直接算）
```

- 含义：**每承担 1 单位偏离风险（跟踪误差），换来多少超额收益**。
- 它衡量的是"超额收益的性价比"，不是超额收益的绝对值。指增的核心成绩单。
- 经验线：IR > 0.5 不错，> 0.75 好，> 1 优秀。

> **关键连接点**：IR 和你在练习里算过的 **ICIR = mean(IC)/std(IC)** 是**同一个数学形式**。
> ICIR 是"因子信号"的性价比（每单位 IC 波动换多少 IC 均值），IR 是"组合超额"的性价比。
> 你能把因子做出高 ICIR，才可能把组合做出高 IR。

### 2.5 超额最大回撤（excess max drawdown）

- 先造超额净值曲线，再算它从峰到谷的最大跌幅。
- 含义：**你相对指数，最惨的时候落后了多少**。指增客户最怕"增强变增弱"，这个指标就是衡量最坏情况。

### 2.6 月度超额胜率（monthly win rate）

```
胜率 = (月度超额 > 0 的月份数) / 总月份数
```

- 衡量你跑赢指数的**稳定性**：60% 胜率 = 10 个月里 6 个月跑赢。
- 它和 IR 互补：IR 高但胜率低，说明靠某几个月爆发；胜率高且 IR 稳，才是"稳稳增强"。

### 2.7 暴露（Exposure）

"暴露"= 你的组合在某个**维度**上，相对基准**偏离了多少**。常见三个：

- **行业暴露** = 组合在某行业的权重合计 − 基准在该行业的权重合计。约束 |…| ≤ 3%。
- **市值暴露** = 组合的市值特征 − 基准的市值特征。约束 ≈ 0（市值中性）。
- **风格暴露** = 在估值/动量/波动率等风格因子上的偏离（进阶概念，本题先用行业+市值）。

### 2.8 beta 与 alpha（为什么必须中性化）

- **beta**：随大盘、行业、市值等一起涨跌的部分（系统风险）。它是"免费的"，买了就自动有。
- **alpha**：独立于这些风险、由你的选股能力带来的超额。

**指增必须把 beta 剔掉，只留 alpha**，原因：

> 练习 03 你已经亲手发现 ln市值 IC = -0.0498（强小市值溢价）。
> 如果你不控市值，你的"超额"里很大一块其实只是"多买了小票"赚的小市值 beta，
> 而 beta 长期可能反转/失效，也不是客户付费买的能力。所以要用约束把这些 beta 逼成 0，
> 剩下的超额才叫真 alpha。

## 3. 数学框架

### 3.1 组合权重 = 基准权重 + 主动权重

设基准里股票 i 的权重是 `b_i`，你的组合权重是 `w_i`，则：

```
主动权重（active weight）Δw_i = w_i − b_i
```

- Δw_i > 0：你**超配**了 i（比指数更重仓）。
- Δw_i < 0：你**低配**了 i。
- Σ Δw_i = 0（超配的钱来自低配，总权重还是 1）。

### 3.2 超额收益 = 主动权重 · 股票收益

```
r_a = r_p − r_b = Σ w_i r_i − Σ b_i r_i = Σ Δw_i · r_i
```

**这句是指增的命脉**：超额收益完全由"你相对基准的偏离"决定。你没偏离的仓位，赚的亏的正好和基准抵消，不产生超额。

### 3.3 约束的数学表达（第 3 步的本质）

- **满仓**：Σ w_i = 1，且 w_i ≥ 0（A 股不能裸卖空）。
- **行业偏离**：对每个行业 k，| Σ_{i∈行业k} w_i − Σ_{i∈行业k} b_i | ≤ 3%。
- **市值中性**：组合的市值暴露 ≈ 0，即 Σ Δw_i · ln(市值_i) ≈ 0（用 ln市值当市值特征）。
- **持仓数**：约 100 只（题目给定；持仓越少越能表达因子，但 TE 越大）。

### 3.4 指标计算公式汇总（日度口径）

| 指标 | 公式 | 说明 |
|---|---|---|
| 日度超额 | `e_t = r_p,t − r_b,t` | 一切的基础 |
| 年化超额 AR | `(Π(1+e_t))^(252/T) − 1` | T=交易日数 |
| 年化跟踪误差 TE | `std(e_t) × √252` | 超额收益的波动 |
| 信息比率 IR | `AR / TE` = `mean(e_t)/std(e_t) × √252` | 超额性价比 |
| 超额最大回撤 | `min(1 − 净值_t/历史峰值)` | 超额净值的最坏情况 |
| 月度超额胜率 | `#(月度超额>0)/总月数` | 跑赢稳定性 |

## 4. 每一步详解（对应题目）

### 第 1 步：股票池 = 中证 500 **当期**成分

**为什么强调"当期"——第一道陷阱 = 前视偏差（look-ahead bias）：**

- 中证 500 成分**每年 6 月、12 月定期调整**（踢出差的、纳入好的）。
- 用"现在的成分"回测 2016 年 = 在 2016 年就偷看了未来谁进谁出 → 回测虚高。
- 正确做法：每个调仓时点用**那个时点真实的成分名单**（PIT 口径）。这和练习 01 的动态股票池、练习 04 的公告日对齐是同一个纪律。

**数据来源**：akshare `index_stock_cons_csindex(symbol="000905")`（中证指数公司口径，支持按历史日期取成分），需逐期抓取存档。

### 第 2 步：合成因子 → 打分

**复用练习 05**：反转 / 动量 / 换手 / ROE / EP 五因子，行业+市值中性 + rank，再用 IC 加权合成一个"打分"。

- 打分越高 = 越该超配。
- 但这次**只在 500 只成分股内打分**，不是全市场——指增只允许你在指数里动权重。
- 练习 07 的结论给了信心：反转因子 IC 是"平原"（稳健），打分器可信。

### 第 3 步：组合 = 100 只 + 两个约束

指增和普通选股最大的不同。**不是"买打分最高的 100 只就完事"**，而是"在指数权重基础上做偏离 + 加约束"。

**两种做法：**

- **方法 A（简化，教材本意）**：成分内按打分排序取前 100 只，打分加权（或等权）；再对行业偏离 >3% 的行业做平衡（超配多的砍、低配的补）。这是可落地的做法，难度 ★★★ 匹配。
- **方法 B（严格，加分项）**：二次规划/优化器，目标 `max Σ w_i · score_i`，约束满仓、个股权重上下限、行业偏离 ≤3%、市值中性、跟踪误差上限。这是真实私募的做法。

**两个约束的意义（再强调一次）：**

- **行业偏离 ≤3%**：防止"押对行业"赚的是行业 beta 而不是选股 alpha。
- **市值中性**：防止"多买小票"赚的是练习 03 发现的小市值 beta。

### 第 4 步：月度调仓，回测 2016 至今，基准 = 中证 500

- **月度调仓**（约 21 个交易日），贴近真实指增产品。
- **必须加真实摩擦**（练习 06 那套：次日开盘成交、成本、涨跌停、停牌）——指增的换手和成本直接吃超额，别用"理想成交"骗自己。
- **每天算超额** `e_t = r_p,t − r_b,t`，后续所有指标都从这条序列来。

### 第 5 步：算 5 个指标

全部基于**超额收益序列**（不是组合绝对收益），见 §3.4 公式表。核心看 **IR**。

### 验收：超额净值曲线 + 指标表 + 行业/市值暴露图

- **超额净值曲线**：画 `(1+e_t)` 的累积曲线，标题写"**超额**"，不是"收益"。
- **指标表**：AR / IR / TE / 超额最大回撤 / 月度超额胜率。
- **行业/市值暴露图**：每期各行业的偏离柱状图（或热力图）+ 市值暴露时间序列，证明你的约束真的生效了（暴露一直压在小范围）。

## 5. 关键陷阱（按严重程度排序）

1. **前视偏差**：用现在的成分/用 hfq 价算市值。→ 当期成分 + 不复权价算市值。
2. **风格 beta 泄漏**：不中性化，超额全是小市值/行业 beta。→ 练习 03 的中性化 + 本节约束。
3. **成本与换手**：指增月度调仓 + 打分驱动的换手，成本会吃掉超额。→ 练习 06 的摩擦模型。
4. **过拟合**：为了把样本内 IR 做高而反复调因子/参数。→ 练习 07 的纪律：看 Walk-forward、别只信样本内。
5. **幸存者偏差**：股票池混入"现在还在、当年已退市"的股票。→ 练习 01 的动态/含退市口径。

## 7. 求职视角 / 常见面试问题

指增是量化私募的现金牛产品，面试常问（提前想清楚）：

1. "你的指增 IR 多少、TE 多少？" —— 看 §2.3/2.4，能报出数字并解释含义。
2. "怎么控行业暴露和市值暴露？" —— §3.3 的约束 + 练习 03 的中性化。
3. "超额里有没有混入 beta？怎么证明是 alpha？" —— §2.8 + 暴露图。
4. "为什么不用现在的成分？" —— §5.1 前视偏差。
5. "月度调仓成本影响多大？" —— 练习 06 的盈亏平衡成本 1.03%、换手 0.49 这些真数字。
