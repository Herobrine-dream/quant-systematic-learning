# 练习 08 结果分析：中证 500 指数增强

> 脚本 `backtest_enhance.py`，数据 2016-01 至 2024-12，月度调仓。
> 股票池 = 中证500 当期成分（PIT，baostock 逐月取）；打分 = 5因子 IC 加权（练习05口径）；
> 组合 = 成分内打分前 100 等权 + 行业偏离 ≤3%；基准 = 中证500；单边成本 0.1%。

---

## 结论先行

**指增做出来了，成绩及格偏优，但有一个必须诚实指出的缺陷——市值中性没真正达成。**

| 指标 | 值 | 判读 |
|---|---|---|
| 年化超额 | **+3.89%** | 每年比中证500多赚 ~3.9% |
| 信息比率 IR | **0.60** | >0.5 及格，>0.75 才优秀 |
| 跟踪误差 TE | 6.43% | 贴指数程度尚可 |
| 超额最大回撤 | -13.54% | 相对指数最惨落后 ~13.5% |
| 月度超额胜率 | 57.0% | 约 10 个月里 5.7 个月跑赢 |
| 组合年化（参考） | 4.88% | vs 基准 0.52% |

一句话：**超额 3.9% / IR 0.6，是个能交代的指增结果**；但下面这个缺陷会直接削弱"超额是真 alpha"这个结论。

---

## 最重要的发现：市值暴露差 = -0.318（小盘 tilt，未中性）

市值暴露图显示：**组合的 ln市值加权暴露，平均比基准低 0.318**，且全程稳定为负（std 仅 0.085）。

```
exp(-0.318) ≈ 0.73  →  组合的市值中枢只有基准的 ~73%，即系统性偏小盘。
```

**为什么必然发生**（不是 bug，是方法本身）：

- 基准（中证500）是**市值加权**，ln市值暴露被少数大盘股拉高；
- 组合是**前100等权**，大票小票一视同仁 → 天然比市值加权基准更偏小盘。

**为什么这很重要**（直接呼应练习 03）：

- 练习 03 你已经亲手测出 **ln市值 IC = -0.0498**（强小市值溢价）。
- 所以这 3.89% 的超额里，**有一部分不是选股 alpha，而是"多买了小票"的小盘 beta**——那是免费的、可能反转的 beta，不是客户付费买的能力。
- 结论：**因子层面做了市值中性 ≠ 组合层面市值中性**。等权组合绕过了因子中性化，把小盘暴露又带回来了。

**若要真正中性（下一步可做）**：在组合层面加市值约束，或改用"市值中性加权"（让组合的市值暴露对齐基准），而不是简单等权。

## 其余发现

- **IR 0.60 的成色**：把上面 -0.318 的小盘 beta 剔除后，纯选股 alpha 会**低于 0.60**。这个 IR 是"含小盘 beta"的上限估计。
- **超额回撤 -13.5%**：不算小，说明某些年份（如 2017 大盘强、小盘弱，或 2021 风格切换）增强是"增弱"的。指增客户最怕这个，值得回看是哪几段。
- **胜率 57%**：稳但不算高，说明超额不是"每月都赢"，而是"多数月小幅赢 + 少数月大输"的组合。

---

## 口径与局限（诚实）

1. **基准权重用总市值代理**：中证500 是自由流通市值加权，这里用 不复权价×总股本 近似，会有偏差（但对结论方向无影响）。
2. **市值中性未达成**（见上），是本版最大的已知缺陷。
3. **因子打分**：5因子（反转/动量/换手/ROE/EP）行业+市值中性 rank + 滚动 IC 加权，全市场算 IC、成分内选股。
4. **收益口径**：月末收盘 → 下月末收盘，单边成本 0.1%；未叠加练习06 的涨跌停/停牌/T+1 摩擦（月度低频，影响远小于日频）。
5. **成分数据**：baostock 逐月当期成分（PIT 正确）；akshare/tushare 无历史成分接口。
