# 练习 05 题目：多因子合成并跑赢等权基准

> 来源：教材《量化系统化学习与实战教程》第五章 · 难度 ★★

**目标**：完成第一次"多因子 → 组合"的闭环。

**步骤**
1. 从练习 02~04 的因子里选 5 个逻辑不同的（反转、动量、换手、ROE、EP）。
2. 中性化 + rank 后计算两两相关性，剔除相关性 > 0.7 的。
3. 三种合成：等权 / IC 加权 / ICIR 加权。
4. 每种合成都跑分层回测（含成本 0.1% 单边），比较组合 ICIR。

**验收**：合成方法对比表（组合 ICIR、超额年化、换手、最大回撤）。**结论里必须回答："复杂方法有没有跑赢等权？"**
