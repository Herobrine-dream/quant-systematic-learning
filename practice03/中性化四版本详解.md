# 练习 03 · 因子中性化四版本详解

> 本练习要回答的核心问题：**ROE 这个因子的预测力（或没有预测力），到底来自「盈利」本身，还是来自它顺带暴露的行业 / 市值？**
> 这是整个量化入门里最关键的一课：学会把 **Alpha（真本事）** 和 **Beta / 风格暴露（沾别人的光）** 分开。

---

## 一、为什么要做中性化对比

一个横截面因子（比如 ROE）天然和很多东西相关：

- 它和**行业**强相关 —— 银行平均 ROE ≈ 12%，白酒平均 ROE ≈ 30%，直接比绝对值是"关公战秦琼"；
- 它和**市值**强相关 —— 小票、大票的盈利结构系统不同，而市值本身在 A 股就是强因子（小市值溢价）；
- 它还可能被**极端值**主导 —— 净资产很小的公司，ROE 能到几百上千。

如果不做处理，你测出来的 IC 其实是下面这锅大杂烩：

> **IC(原始ROE) = 行业暴露 + 市值暴露 + 极端值噪声 + 一点点真实盈利信号**

你根本说不清自己在赚什么钱。教材的原话是：

> **「如果中性化后 IC 掉一半以上，说明原因子主要是市值/行业暴露。」**

四版本对比，就是把这锅大杂烩**一层层拆开**，看每拆掉一层，IC 怎么变。

---

## 二、四个版本的定义

### 总览

| 版本 | 因子值是什么 | 排除了什么 |
|---|---|---|
| **A 原始** | ROE 原值，什么都不做 | 什么都不排除 |
| **B 仅去极值** | MAD 3× 截断后的 ROE | 极端值 |
| **C 行业中性** | ROE 减去「行业能解释的部分」 | 极端值 + 行业 |
| **D 行业+市值中性** | ROE 减去「行业+市值能解释的部分」 | 极端值 + 行业 + 市值 |

---

### 版本 A —— 原始（Raw）

- **因子值**：`ROE = 归母净利 / 归母权益`，不做任何处理。
- **用到数据**：利润表 `PARENT_NETPROFIT` + 资产负债表 `TOTAL_PARENT_EQUITY`（最新已披露年报，PIT）。
- **怎么算**：直接相除，取最新已披露年报。
- **排除了什么**：什么都不排除。
- **隐患**：极端值主导。某公司净资产 100 万、净利 100 万 → ROE = 100%，会把排名搅乱；Spearman 秩相关虽然抗极端，但分层时极端值会独占一组，污染组内均值。

---

### 版本 B —— 仅去极值（Winsorize）

- **因子值**：MAD 3× 截断后的 ROE。
- **公式**：

  ```
  med   = median(ROE)                       # 横截面中位数
  MAD   = median(|ROE - med|)               # 绝对偏差的中位数
  ROE_w = clip(ROE,
               med - 3 × 1.4826 × MAD,      # 下限
               med + 3 × 1.4826 × MAD)      # 上限
  ```

  （`1.4826` 是让 MAD 与正态分布标准差可比的常数。）
- **用到数据**：同 A（年报两字段）。
- **怎么算**：**每个调仓日**在横截面上算一次中位数和 MAD，再截断。
- **排除了什么**：极端值（异常高 / 低）。
- **回答什么**：单独隔离"极端值处理"这一步——若 A → B 的 IC 变化很大，说明之前主要被极端值驱动。

---

### 版本 C —— 行业中性（Industry-Neutral）

- **因子值**：ROE 减去「由行业能解释的部分」后的**残差**。
- **公式**（每个调仓日在横截面上做一次 OLS）：

  ```
  ROE_w  =  行业哑变量矩阵 · β  +  ε
  因子   =  ε      （即残差，行业解释不了的那部分）
  ```

- **通俗解释**：把每个股票的 ROE 换成 **「它比本行业平均高 / 低多少」**。
- **用到数据**：版本 B 的数据 + **行业分类**（每只股票属于哪个行业）。
- **怎么算**：
  1. 先做 B 的去极值；
  2. 把行业变成哑变量（one-hot，每个行业一列，属于该行业 = 1，否则 = 0）；
  3. 用最小二乘（OLS）回归，取残差。
- **排除了什么**：极端值 + 行业。
- **例子**：

  > 银行平均 ROE ≈ 12%，白酒平均 ROE ≈ 30%。
  > 某银行 ROE 15%，某白酒 ROE 25%。
  > **按绝对值**：白酒(25%) > 银行(15%)，会觉得白酒"质量更好"。
  > **按行业内**：银行 15% − 12% = **+3 个点**；白酒 25% − 30% = **−5 个点**。
  > 所以行业中性后结论反过来——这家银行才是"行业内优秀"，白酒是"行业内落后"。

  这就是教材反复强调的"金融股和实业股指标不可比，必须行业内比较"。

---

### 版本 D —— 行业 + 市值中性（Industry & Size-Neutral）

- **因子值**：ROE 减去「由行业 + 市值能解释的部分」后的**残差**。
- **公式**（在 C 的回归里多加一个自变量 `ln(市值)`）：

  ```
  ROE_w  =  行业哑变量 · β₁  +  ln(市值) · β₂  +  ε
  因子   =  ε
  ```

- **通俗解释**：把每个股票换成「扣掉行业、市值影响后，还剩多少盈利信号」。
- **用到数据**：版本 C 的数据 + **市值**（= 不复权收盘价 × 总股本）。
- **怎么算**：在 C 的 OLS 里多加一列 `ln(市值)`，取残差。
- **排除了什么**：极端值 + 行业 + 市值。
- **为什么必须剥市值**：ROE 和市值相关，而市值本身在 A 股是强因子（小市值溢价）。不剥掉市值，ROE 因子可能偷偷在"买小盘"。剥掉后剩下的，才是**纯盈利 Alpha**。

> ⚠️ 注意：中性化里的所有回归，都是**每个调仓日在横截面上各做一次**，而不是全样本做一次——这是 PIT 纪律，避免用到未来信息。

---

## 三、区分这四个版本的必要性

| 对比 | 回答的问题 | 若 IC 明显变动，说明… |
|---|---|---|
| **A vs B** | 极端值有没有在捣乱？ | 信号里有相当一部分来自极端值 |
| **B vs C** | **行业暴露**占了多少？ | 之前主要靠行业，不是个股本事 |
| **C vs D** | **市值暴露**占了多少？ | 之前主要靠市值 / 小盘 |

**判据（教材练习 03 原文）**：中性化后 IC 掉一半以上 → 原因子主要是市值 / 行业暴露。

**必要性一句话总结**：不做四版本对比，你就不知道自己的因子"卖的是自己的货，还是蹭了行业/市值的光"。这直接决定它能不能进多因子、能不能实盘。

---

## 四、第 5 个参照：`ln(市值)` 本身当因子

练习 03 还要求多做一件事：**把 `ln(市值)` 单独当一个因子，看它自己的 IC**。

- **目的**：知道"市值"这个暴露在 A 股到底有多强，作为解读 C vs D 的**参照系**。
- **若 `ln(市值)` 本身 IC 很强**，而 D 版本比 C 版本 IC 变化大，就印证了"ROE 的一部分信号来自市值"。
- **计算**：`ln(市值) = ln(不复权收盘价 × 总股本)`，同样去极值 + 转 rank 后算 RankIC。

## 五、延伸情况（不止这四种）

四版本是最小骨架。核心原理只有一句：**中性化 = 把因子对「任何你不想要的暴露」做回归、取残差**。既然"不想要的暴露"清单可以随便列，版本就能无限扩展：

### 1. 去极值的变体
- MAD 3×（本练习用）/ 1%、99% 分位缩尾 / ±3σ 截断 / 直接删除极端值。
- 取舍：MAD 抗极端最稳、分位缩尾最直观、±3σ 依赖正态假设。

### 2. 标准化的变体
- z-score / rank / 映射成均匀分位。
- rank 最稳健（只看排序、不看量纲），z-score 保留量纲信息。

### 3. 更多中性化维度
- 市场 **Beta**（剥掉对大盘的敏感度）；
- **Barra 风格因子全套**：价值(BP)、动量、波动率、流动性、成长、质量、杠杆…
- 换手率 / 流动性暴露；
- 工业界常用"对 10~30 个风格因子一起中性化"。

### 4. 正交化（多因子阶段才用）
- 不是对风格中性，而是让多个因子之间**互相正交**、去掉冗余信息（对应教材第 4 章"多因子合成"）。

### 5. 缺失值处理变体
- 直接剔除 / 行业均值填充 / 中位数填充（并统计覆盖率，教材门 2 要求 ≥70%）。

## 六、完成练习 03 的意义

1. **回答"我赚的是 Alpha 还是 Beta"** —— 这是面试八问里必问的一条："你因子中性化前后差多少？"
2. **诊断 ROE 为什么 ≈0** —— 当前 ROE 原始 IC ≈ −0.009，四版本能告诉我们：是不是市值 / 行业把盈利信号**反向抵消**了。若 D 版本翻正，说明 ROE 有料，只是被暴露掩盖；若 D 版本还是 ≈0，才说明 ROE 在这个样本里真没独立信号。
3. **建立"归因"思维** —— 以后每做一个因子，第一反应是"它是不是某个已知风格因子的伪装"，而不是"回测曲线好不好看"。
4. **验收标准**（教材门 3 + 练习 03）：四版本对比表 + 一段结论。

## 七、数据缺口与后续步骤

| 需求 | 现状 | 处理 |
|---|---|---|
| 行业分类 | universe 里无行业字段 | 待爬（东财行业板块 / 申万一级） |
| 市值（`ln(市值)`） | 日线是后复权(hfq)，算市值会偏 | 待爬不复权收盘价 |

**后续步骤**：
1. 爬「行业分类」（轻量）；
2. 爬「不复权收盘价」（中量，只存 close 一列）；
3. 写四版本对比脚本（原始 / 仅去极值 / 行业中性 / 行业+市值中性 + `ln(市值)` 参照）；
4. 输出四版本对比表 + 结论。

> 其中第 2 步爬完，后面做 PE / PB / EP / BP 等估值因子也一并解锁，一劳永逸。
