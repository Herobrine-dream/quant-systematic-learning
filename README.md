# 量化投资系统化学习与实战

很荣幸能由优秀的您打开这份README，我是一名大二的金融科技专业的学生，在学习专业知识的空余探索自己的职业发展道路。量化交易是一条难度大，要求高的职业道路，在学习的途中我也有很多的思考和感悟，借助AI的辅助我将思路和体会整理成一份系统化教材，一份面向量化入门者的系统化学习教程，以及配套的12级练习的完整实现，希望能给同样在初步尝试量化领域的本科生一点灵感，也希望得到优秀的朋辈前辈专业宝贵的交流建议。再次感谢您的光顾，对您致以深深的感谢。

## 这个项目是什么

核心是一份教材——《量化系统化学习与实战教程》（位于 [`量化入门学习日志教材/`](量化入门学习日志教材/量化系统化学习与实战教程.md)）。

它的定位**不是一本"知识百科"，而是一份"研究作业标准（SOP）+ 训练计划"**：读完并做完练习后，你应该能随便给自己一个策略想法，都按固定流程把它做成一份能拿得出手的研究报告，并清楚它为什么可能失效。

## 教材讲了什么

| 第四章 | AI 时代如何系统化学习并入行 |
| 第五章 | 12 级练习阶梯（本项目的实践部分） |

## 12 级练习做了什么

从"数据体检"一路走到"模拟盘收尾"，每道题的完整实现都在对应 `practiceNN/` 目录（题目、回测脚本、结果图表、结果分析）：

| 练习 | 主题 | 一句话结论 |
|---|---|---|
| 01 | 数据体检：亲手造一次幸存者偏差 | 幸存者偏差让反转策略年化高估约 1%，对 IC 影响 <0.002 |
| 02 | 完整复现一个经典因子（ROE 八步流程） | ROE 的 IC ≈ -0.009、不显著——"无效"也是结论 |
| 03 | 中性化对比实验 | 市值暴露是 ROE 负 IC 的元凶（ln 市值 IC = -0.0498） |
| 04 | 财务因子与 PIT 生死线 | 报告期 vs 公告日差 +0.0099，这就是未来函数 |
| 05 | 多因子合成 | 换手因子最强（ICIR 0.99），IC 加权跑赢等权 |
| 06 | 真实回测改造 | 现实摩擦合计只吃 35bp，盈亏平衡成本约 1.03% |
| 07 | 防过拟合三件套 | IC 是平原、年化是悬崖；最优参数每轮都跳 |
| 08 | 中证 500 指数增强 | 超额 3.89%、IR 0.60，但市值暴露差 -0.318 |
| 09 | 归因 | 超额几乎全被市值因子解释，Alpha = -3.16%——赚的是 beta |
| 10 | 可转债双低轮动 | 年化 11.37%，7 年 6 年跑赢基准 |
| 11 | 事件驱动（业绩预告超预期） | PEAD 显著（CAR(60) +3.23%），2024 首次转负 |
| 12 | 收尾总结 + 开放性试题 | 没有示范答案，把接力棒交还给读者 |

## 目录结构

```
.
├─ 量化入门学习日志教材/
│   └─ 量化系统化学习与实战教程.md   ← 教材（SOP + 训练计划）

│   ├─ scripts/                       ← 数据爬取脚本（断点续传）
│   ├─ results/                       ← 图表与指标表（已提交）
│   └─ 结果分析.md                     ← 结论、失败与反思
```

> **关于原始数据**：`practiceNN/data/` 下的原始数据约 **3.6 GB**（后复权日线、三大报表、转债日线、业绩预告等），超过 GitHub 的仓库与单文件限制，因此**未包含在本仓库中**。各练习 `scripts/` 下的爬取脚本支持断点续传，按文档说明执行即可重新获取；`results/` 中的图表与指标表是基于全量数据跑出的真实结果，可直接查看。

## 技术栈与口径

- **环境**：Python + pandas / numpy / pyarrow，全程本地脚本化，不依赖任何平台
- **数据源**：akshare（东方财富，行情/财务/转债/业绩预告）、baostock（指数历史成分）、中证官网（指数日线）
- **口径纪律**：收益类因子用后复权、估值/市值类因子用不复权价；财务数据按公告日（PIT）对齐；回测含成本/涨跌停/停牌/T+1

## 怎么开始

1. 从 [`量化系统化学习与实战教程.md`](量化入门学习日志教材/量化系统化学习与实战教程.md) 第一章读起（约 30 分钟）；
2. 跳到第五章，从练习 01 开始做，边做边回查第二章；
3. 每道练习做完，可对照对应 `practiceNN/` 目录里的分析文档，看一个"真实做出来会是什么样"的参考。
